# Sonora — Birds of India

A static, interactive bird guide with bird profiles, calls, soundscape, quiz, field kit, and radar pages.

## Run locally

Open `index.html` in a browser. The bird photos are included in `assets/birds/`.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. The website URL will be `https://maheswarisomashekar-code.github.io/BirdsHub/` after deployment finishes.
